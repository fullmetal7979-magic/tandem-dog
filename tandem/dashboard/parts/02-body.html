계정과 도구가 바뀌어도 세션은 하나

Claude 계정 여러 개, Codex 계정, 여러 PC가 한 프로젝트를 하나의 세션처럼 이어 갑니다. 쓰는 계정을 전환하면 그 도구에 맞는 세션 팩이 만들어지고, 끝난 결과를 붙여넣으면 장부에 이어서 기록돼요.

가상 세션 키트 · 어느 PC·어느 AI에서든 같은 세션

세션의 원본을 저장소 안 .tandem/SESSION.md에 둬요. git으로 모든 PC에 따라가고, Claude Code는 시작할 때마다 자동으로 pull해서 읽어요(시작 훅). Codex는 AGENTS.md 지시로 읽어요. 붙여넣기 없이 같은 세션에서 시작해요.

한도는 계정 하나를 같이 씁니다

여러 PC에서 동시에 Claude를 돌리면 같은 계정의 사용량이 그만큼 빠르게 줄어듭니다. 세션 창 타이머와 모든 PC의 부하를 같이 보면서 무거운 작업을 배분하세요.

세션 창 타이머
전체 PC 합산 부하
한도를 아끼는 배분 요령
무거운 작업(대규모 리팩터링, 여러 에이전트 동시 실행)은 한 PC에서만 돌리고, 나머지 PC는 리뷰·테스트·문서처럼 가벼운 일을 맡기세요.
여러 PC가 같은 파일을 읽게 하지 마세요. 같은 맥락을 여러 번 읽는 만큼 사용량도 여러 번 듭니다. 바통 프롬프트로 요약만 넘기세요.
한도에 가까워지면 고부하 PC의 작업을 마무리하고, 바통을 남긴 뒤 창이 리셋될 때 이어가세요.
정확한 남은 한도와 리셋 시각은 claude.ai의 설정 > 사용량 화면이 기준입니다. 이 타이머는 모든 PC가 같은 시계를 보기 위한 보조 도구예요.

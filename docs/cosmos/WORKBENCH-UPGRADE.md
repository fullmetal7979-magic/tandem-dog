# 작업 도구 및 UX 구현 기록

2026-10-26. 채팅 입력창 하단 **작업 도구**에서 보내기 전·복원·사용량·인계/검증·연결을 연다. `Cmd/Ctrl+Shift+K`도 지원한다. 모델 메뉴는 `Cmd/Ctrl+Shift+M`이다.

## 개선한 10가지

| 항목 | 실제 동작 |
|---|---|
| 반응형 배치 | 은하수의 작은 왼쪽 패널, 작업 도구 카드·입력·버튼을 창 너비에 맞춰 줄바꿈한다. |
| 채팅 중심 홈 | 프로젝트 이름과 작업 상태, 작은 실행 버튼을 먼저 보여 준다. 기기 지도는 펼칠 때 본다. |
| 모델 가용성 | 모델 검색·즐겨찾기와 공급자 연결 설정을 사용하고 연결 탭에서 계정 준비 상태를 확인한다. |
| 모델 전환 복구 | 전환 전 수용량·압축 필요 여부를 표시한다. 실패 시 원본·초안을 유지하고 재시도한다. |
| 사용량 구분 | 입력·출력·캐시 읽기·예상 USD·모델 요청 횟수와 확인되지 않은 요청을 구분한다. |
| 연결 순서 | GitHub 로그인 → 저장소 → 이 기기 동기화 → 다른 기기 순서로 상태와 설정 이동을 제공한다. |
| 기기 간 작업 이력 | 대화 내보내기·이어받기·복원에 원본 작업 ID를 유지한다. |
| 중지 피드백 | 중지 요청과 실제 응답 종료를 알린다. 이미 실행한 코드와 별도 백그라운드 작업의 범위도 설명한다. |
| 성능 | 작업 도구·모델 전환·컨텍스트 검사를 필요할 때 불러온다. 사용량 탭만 가벼운 조회로 갱신한다. |
| Mac 접근성 | 창 버튼 안전 영역, 키보드 탭 이동·Escape·포커스 복귀, 시스템 동작 줄이기를 지원한다. |

## 추가한 10가지

| 항목 | 실제 동작 |
|---|---|
| 전송 전 검사 | 현재 메시지·첨부와 로컬 토큰 추정, 자동 참조 파일, 기존 대화/도구 검사. 초안 첨부 제외. |
| 코드·대화 복원 | 별도 Git 인덱스로 미커밋 코드와 당시 대화를 저장한다. 원본 인덱스·파일을 유지하며 새 worktree에서 복원한다. |
| 일/프로젝트 한도 | 로컬 SQLite에 요청을 예약하고 완료 사용량을 기록한다. COSMOS 하위 에이전트와 대화 압축도 포함한다. |
| 담당 파일 표시 | Claude/Codex 담당 경로를 수동 등록하고 폴더·파일 중복을 알린다. 24시간 보관하며 강제 잠금은 아니다. |
| 프로젝트 컨텍스트 규칙 | 항상 포함할 상대 파일, 제외 패턴, 프로젝트 지침을 기기에 저장한다. 변경 없는 자동 컨텍스트는 재사용하고 바뀐 참조는 교체해 누적을 막는다. |
| 인계 카드 | 목표·변경 파일·확인된 검증·남은 작업을 AI 요청 없이 구성하고 복사한다. |
| 초안 관리자 | 최근 20개·7일간 텍스트/첨부 초안을 복구·삭제한다. 다른 초안을 복원하기 전에 현재 초안을 보관한다. |
| 모델 전환 미리보기 | 대상 모델의 실제 런타임 수용량을 조회한다. 압축 시 추가 요청 가능성을 전환 전에 알린다. |
| 연결 진단 | Git·GitHub·AI 계정·동기화·폰 설정을 제한 시간 내 조회하고 해당 설정으로 이동한다. |
| 완료 검증표 | 실제 도구 명령의 숫자 종료 코드로 통과/실패를 표시한다. 결과가 없거나 실행 중이면 확인 필요로 남긴다. |

## 정리한 10가지

1. 시간대별 큰 인사말을 제거했다.
2. 홈의 거대한 세 버튼을 작은 관련 동작으로 줄였다.
3. 핵심 작업 버튼은 메시지 입력·프로젝트 열기·저장하고 작업 넘기기처럼 동작을 설명한다. 은하수/기기 지도 명칭은 연결 화면에 유지한다.
4. 현재 상태에서 해당하지 않는 홈 동작은 노출하지 않는다. 조종석 잠금 중 메시지 버튼은 잠금 상태를 보존한다.
5. 연결 CTA를 새 은하수 만들기·기존 은하수 찾기로 줄였다.
6. 완료·닫은 시작 가이드는 자동 재등장하지 않는다. 작업 도구에서 다시 열 수 있다.
7. 장식용 반복 효과를 끄고 선택·등장·진행·완료 효과를 짧게 사용한다. 효과 끄기와 OS 동작 줄이기를 지원한다.
8. 설정의 중복 준비표를 제거하고 실제 연결 화면으로 안내한다.
9. 기본 사이드바를 대화·프로젝트·변경·실행으로 정리했다. 직접 고친 배치는 유지하며 나머지는 더 보기로 연다.
10. 사라진 심플/고급 UI 모드의 렌더러 코드를 제거했다. 기존 저장 키와 CLI 이름 등 호환성은 유지한다.

## 데이터·한도 범위

- 집계는 이 기기의 COSMOS 요청부터 시작한다. 외부 Claude 앱, 다른 기기·계정 전체 사용량은 집계하지 않는다. 프로젝트 범위는 설정된 로컬 폴더와 하위 폴더이며, 별도 복원 폴더는 별도 프로젝트다.
- 요청 횟수는 공급자 호출 전에 원자적으로 예약한다. 토큰/USD는 최종 사용량으로 정산하므로 동시 요청·진행 중 응답이 상한을 넘을 수 있다. 공급자 SDK 내부 재시도 횟수와 실제 청구액을 보장하는 결제 제한은 아니다.
- 가격·사용량이 불명확하면 해당 금액/토큰 한도에서 추가 요청을 막는다. 강제 종료로 남은 요청도 확인 필요로 전환한다. 확인 처리는 이미 알려진 수치와 요청 횟수를 지우지 않는다.
- 컨텍스트는 파일당 32KB·합계 64KB 안에서 참조한다. 프로젝트 밖 심볼릭 링크, 비밀 파일/토큰, 바이너리는 자동 참조하지 않는다. 제외는 자동 참조에 적용하며 기존 사용자 대화와 명시적으로 요청한 도구 접근을 수정하지 않는다.
- 복원 지점은 프로젝트당 20개, 변경 파일 1,000개·개별 20MB·합계 100MB 이내다. Git 기록에 이미 있던 내용은 기반 커밋에 속한다. 로컬 ref를 원격으로 푸시하지 않는다.
- 대화는 저장 시점의 사본이다. 복원 자체는 AI를 호출하지 않는다. 복원 대화가 모델에 맞지 않으면 코드는 복원하고 대화 실패 이유/폴더를 알린다. 자동 유료 압축으로 바꾸지 않는다.
- 초안·정책·사용량 DB·복원 대화는 기기 안에 저장한다. 자동 동기화에 추가하지 않는다.

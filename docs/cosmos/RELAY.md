# 📡 코스모스 릴레이 서버 — 폰으로 이어 하기

PC·맥끼리는 **은하수(비공개 GitHub 저장소)** 만 있으면 교대할 수 있어요.
**폰으로 이어 하려면** 폰과 PC를 이어 주는 작은 서버, *릴레이* 가 하나 필요해요.

- 폰은 직접 AI를 돌리지 않아요. 폰 차례에는 **켜져 있는 PC 한 대를 원격으로 몰고**, 그 PC 화면은 잠겨요.
- 폰과 PC 사이의 대화는 **종단간 암호화**(ECDH + AES-GCM)라서 릴레이 서버도 내용을 읽을 수 없어요.
- 릴레이는 폰용 웹앱(PWA "코스모스")도 함께 내려 줘요. 폰에서는 주소만 열면 돼요.

```
📱 폰 ──(https/wss)──▶ 🛰️ 릴레이 서버 ◀──(wss)── 💻 PC (조종석 담당)
          종단간 암호화: 서버는 봉투만 전달하고 내용은 못 봐요
```

## 준비물

| 무엇 | 예 | 비용 |
|---|---|---|
| 리눅스 서버(VPS) 1대 | Vultr · Lightsail · Oracle Cloud · 국내 VPS | 월 5천~7천 원대 (1GB 메모리면 충분) |
| 도메인 1개 | `relay.내도메인.com` | 연 1~2만 원 (이미 있으면 서브도메인만) |
| SSH 접속 | `ssh root@서버IP` 가 비밀번호 없이(키로) 되면 좋아요 | — |

> 서버 계정 만들기와 결제는 직접 해 주세요. 코스모스는 그 뒤의 설치를 한 줄로 해 줘요.

## 1. 도메인 연결

도메인 관리 화면에서 **A 레코드** 하나를 추가해요.

```
relay.내도메인.com  →  서버 IP (예: 203.0.113.10)
```

몇 분 뒤 `ping relay.내도메인.com` 이 서버 IP로 가면 준비 끝이에요.

## 2. 한 줄 설치 (내 맥/PC에서)

코스모스 소스 폴더에서:

```bash
bash apps/relay/deploy/cosmos/deploy.sh root@203.0.113.10 relay.내도메인.com
```

이 한 줄이 하는 일:

1. 🧱 폰 웹앱을 빌드해요 (`apps/desktop` → `apps/relay/renderer`)
2. 📦 릴레이를 서버 `/opt/cosmos-relay` 로 올려요 (rsync)
3. 🚀 서버에 Docker가 없으면 설치하고, **Caddy(자동 HTTPS) + 릴레이** 를 띄워요
4. ✅ `https://relay.내도메인.com/healthz` 가 응답하면 끝

인증서(Let's Encrypt)는 Caddy가 알아서 받고 갱신해요.

### 서버에서 직접 설치하고 싶다면

소스를 서버에 받은 뒤(`apps/relay/renderer` 는 미리 빌드해서 올려야 해요):

```bash
RELAY_DOMAIN=relay.내도메인.com bash apps/relay/deploy/cosmos/install.sh
```

## 3. 코스모스에 주소 넣기

**🛸 관제실 → 🌌 은하수 → 릴레이 주소** 에 입력해요.

```
wss://relay.내도메인.com
```

이 주소는 은하수로 공유되기 때문에 **다른 PC·맥에는 다시 넣을 필요가 없어요.**

## 4. 폰 연결 (기기마다 처음 한 번)

1. PC 코스모스에서 **🛸 관제실 → 연결** 을 열면 QR 코드가 나와요.
2. 폰 카메라로 찍으면 브라우저에서 코스모스가 열려요.
3. PC에 "이 폰을 허용할까요?" 가 뜨면 **허용** 을 눌러요.
4. 폰 브라우저 메뉴에서 **홈 화면에 추가** 를 하면 앱처럼 쓸 수 있어요.

## 폰에서 이어 하기 — 이어달리기 규칙

| 상황 | 폰에서 보이는 것 | 누르면 |
|---|---|---|
| 연결된 PC가 조종 중 | 💻 집 맥북이 조종 중이에요 | **📱 폰으로 이어하기** — 교대 없이 바로 넘겨받고, PC는 잠겨요 |
| 다른 PC가 조종 중 | 🔒 회사 PC가 조종 중이에요 | **🔁 교대 요청** — 그 PC가 🌙 달을 누르면 넘어와요 |
| 조종석이 비어 있음 | ☄️ 조종석이 비어 있어요 | **☀️ 앉기** |
| 폰이 조종 중 | 🕹️ 조종 중 | **🌙 내리기** — 연결된 PC가 대신 저장·커밋·푸시·업로드해요 |

PC에 돌아왔을 때는 잠금 화면의 **↩️ 이 PC로 되찾기** 를 누르면 돼요. 폰에서 하던 작업은 같은 PC에 그대로 있어요.

> 폰이 조종석에 앉아 있지 않으면, 폰에서 파일 저장·커밋·터미널 입력·AI 지시가 모두 막혀요.
> 두 기기가 같은 프로젝트를 동시에 고치는 일이 생기지 않게 하기 위해서예요.

## 관리

```bash
# 서버에서
cd /opt/cosmos-relay/deploy/cosmos
docker compose logs -f          # 로그 보기
docker compose restart          # 다시 시작
docker compose down             # 끄기 (데이터는 남아요)
```

- **업데이트**: 내 컴퓨터에서 설치 한 줄을 다시 실행하면 돼요.
- **데이터**: 기기 등록 정보는 Docker 볼륨 `cosmos-relay_relay-data` 에 있어요. 대화 내용은 저장되지 않아요(종단간 암호화된 채 지나가기만 해요).
- **방화벽**: 80, 443(TCP), 443(UDP) 만 열면 돼요. 릴레이 내부 포트(9800)는 바깥에 열지 마세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 설치 마지막에 "응답하지 않아요" | 도메인 A 레코드가 서버 IP를 가리키는지, 80·443 포트가 열려 있는지 |
| 폰에서 "연결 안 됨" | PC 코스모스가 켜져 있는지, 관제실의 릴레이 주소가 `wss://` 로 시작하는지 |
| 폰이 잠금 화면만 보여요 | 조종석을 다른 기기가 쓰는 중이에요. 🔁 교대 요청을 보내 주세요 |
| 인증서 오류 | 첫 발급에 1~2분 걸려요. `docker compose logs caddy` 로 확인 |

## 보안 메모

- 릴레이는 **봉투만 전달** 해요. 열쇠는 폰과 PC에만 있어요.
- API 키·OAuth 로그인·MCP 비밀값 같은 민감한 작업은 폰에서 **아예 불가능** 해요(PC 전용).
- 기기 승인은 PC에서만 할 수 있고, 관제실에서 언제든 취소할 수 있어요.
- `TRUST_PROXY=1` 은 Docker 구성(Caddy 뒤)에서만 켜져 있어요. 릴레이를 직접 인터넷에 열 때는 끄고 `TLS_CERT`/`TLS_KEY` 를 쓰세요.

# AgentVille 기획·설계서

> 함께 일하며 자라는 AI 동료들의 마을. 라이프 시뮬레이션과 AI 에이전트를 한 프로그램에 담는다.

## 1. 제품 비전

| 질문 | 답 |
|---|---|
| 누구를 위한가 | 웹 작업·컴퓨터 작업을 AI에게 맡기고 싶지만 매번 처음부터 설명하고 하나하나 지켜보는 데 지친 사람. AI와 일하는 경험이 재미있기를 바라는 사람 |
| 무엇이 다른가 | 캐릭터가 **일을 할수록 실제로 일하는 방식이 좋아지고, 믿을수록 혼자 할 수 있는 일이 늘어난다**. 성장이 숫자에서 끝나지 않는다 |
| 핵심 감정 | "우리 민지가 이제 전용 브라우저로 가격표까지 직접 찾아온다", "하준이는 오른팔이 돼서 이제 안 물어보고 정리해 둔다", "서연이 고양이 생겼네" |
| 한 줄 정의 | 웹·컴퓨터를 쓰는 에이전트 + Muse식 병렬 숙고 + 라이프 시뮬레이션의 욕구·관계·성장 + 신뢰와 꾸미기로 쌓는 애착 |

## 2. 핵심 루프

```
 사용자가 업무를 맡김 ──► 마을이 적임자를 추천 ──► 캐릭터가 책상으로 가서 작업
        ▲                                              │ (계획 → 초안 → 검토, 레벨에 따라 단계가 풀림)
        │                                              ▼
 성장한 캐릭터가 다음 일을 더 잘함 ◄── 보상·기억·성찰 ◄── 결과물 + 사용자 평가
        │
        ├─► 손을 쓰는 업무: 전용 브라우저·작업 폴더·터미널·내 컴퓨터 → 🙋 확인 요청 → 허락이 쌓이면 신뢰 단계 상승
        ├─► 성장하면 옷장이 열림: 새 옷·소품·반려동물로 꾸미기
        └─► 쉬는 시간: 욕구에 따라 커피·낮잠·독서·수다 → 관계와 성격이 변함
```

애착은 세 갈래로 쌓인다. **성장**(레벨·스킬·도구 숙련도가 실제 능력을 바꾼다), **신뢰**(내가 허락하고 칭찬한 만큼 혼자 해내는 범위가 넓어진다), **꾸미기**(함께한 기록이 옷장의 아이템으로 남는다).

## 3. 캐릭터 시스템

### 3.1 구성 요소

| 요소 | 내용 | 변하는 방식 |
|---|---|---|
| 정체성 | 이름, 직업(8종), 배경, 말투(존댓말·반말·격식), 입버릇, 외형 | 사용자가 편집 |
| 레벨 | 전체 경험치로 결정. 다음 레벨 필요치 `round(80 × L^1.45)` | 업무·대화·자기계발 |
| 능력치 6종 | 지능·창의·소통·집중·공감·기술 (1~100) | 레벨 업 시 +3을 직업·성격 가중치로 배분, 업무마다 소폭 상승 |
| 스킬 10종 | 리서치·글쓰기·코딩·기획·디자인·분석·마케팅·번역·교육·상담 (Lv 0~10) | 해당 분야 업무 경험치 |
| 성격 Big Five | 개방성·성실성·외향성·친화성·신경성 (0~100) | 경험에 따라 천천히 표류(하루 최대 ±3) |
| 특성 | 시작 특성 12종 + 획득 특성 14종 | 행동 기록 조건 달성 또는 성찰 |
| 성격 메모 | 성찰이 만든 자유 문장("사용자가 표를 좋아해서 표를 자주 쓰게 됐다") | 성찰 |
| 욕구 5종 | 에너지·포만감·사교·재미·집중 (0~100) | 시간에 따라 감소, 활동으로 회복 |
| 무들렛 | 칭찬받음 +15, 레벨 업 +25, 혹평 −12, 과로 −15 … (기한 있음) | 사건 |
| 열망 | 장기 목표 7종, 단계별 보상, 완수 시 특별 특성 | 진행 상황 |
| 관계 | 캐릭터끼리 우정(−100~100), 사용자 호감도(0~100) | 수다·팀 업무·평가 |
| 기억 | 사건 기억 + 성찰 + 사용자 선호 | 모든 사건 |
| 신뢰 | 사용자 신뢰도(0~100, 시작 10) → 자율성 단계 4개 | 평가·허락·거절 |
| 도구 숙련도 | 장비별 사용 횟수 → 숙련 Lv1~5 | 도구 사용 |
| 외형·옷장 | 8개 슬롯, 기본 아이템 + 성장으로 열리는 아이템 | 사용자가 꾸밈 |

### 3.2 성장이 실제 행동을 바꾸는 방식 (핵심 차별점)

| 성장 지표 | 바뀌는 것 |
|---|---|
| 캐릭터 레벨 1~3 / 4~6 / 7~9 / 10+ | Claude 사고 깊이(effort) `low / medium / high / xhigh` |
| 분야 스킬 Lv2 | **계획 단계** 추가: 초안 전에 접근 계획을 세움 |
| 분야 스킬 Lv4 | **검토 단계** 추가: 초안을 스스로 비평하고 개선본을 냄 |
| 분야 스킬 Lv6 | 기억 검색 수 증가, 사용자 선호를 적극 반영 |
| 분야 스킬 Lv8 | 분야별 **채점 기준표**로 검토 |
| 분야 스킬 Lv10 | 장인 모드: 검토 단계 사고 깊이 한 단계 상승 |
| 스킬별 퍽 | 분야 고유 작업 요령이 프롬프트에 추가(예: 리서치 Lv4 "사실·추정·의견 구분") |
| 특성 | 프롬프트 성향 문장 + 경험치·욕구·품질 보정 |
| 기억·성찰 | 과거 피드백과 교훈을 다음 업무에 반영 |
| 기분 | 품질 보정(0.85~1.1), 말투에 은근히 드러남 |

### 3.4 옷장(꾸미기)

| 슬롯 | 기본 | 성장으로 열리는 것 |
|---|---|---|
| 머리 모양 | 짧은·긴·똥머리·삐죽·포니테일 | 양갈래 Lv2, 곱슬 Lv4 |
| 눈 | 동글·웃는 눈·졸린 눈 | 반짝 눈 Lv3, 윙크 신뢰 50 |
| 옷 | 티셔츠·후드티·셔츠 | 정장 Lv4, 연구복 리서치·분석 Lv5, 앞치마 업무 15건, 망토 Lv8 |
| 소품 | 안경·헤드폰·중절모·리본 | 고깔모자 Lv2, 고양이 귀 Lv3, 베레모 디자인 Lv3·글쓰기 Lv4, 꽃핀 친구 1명, 선글라스 Lv5, 천사 고리 별5 3연속, 왕관 Lv10 |
| 반려동물 | 없음 | 병아리 첫 칭찬, 고양이 Lv5, 강아지 업무 10건, 부엉이 성찰 3번, 꼬마 로봇 도구 40번, 슬라임 Lv8 |
| 색 | 피부 7색, 머리 9색, 옷 13색(직업 색 포함) | 민트 머리 Lv3, 은발 Lv6, 노을빛 칭찬 5번, 칠흑 옷 Lv5, 금빛 옷 꿈 2단계 |

- 아이템 판정은 서버가 한다(`sanitizeAppearance`). 잠긴 아이템이나 없는 값은 무시하고, 모든 항목이 거부되면 오류를 낸다. 새 캐릭터도 기본 아이템만 고를 수 있다.
- 새로 열린 아이템은 연대기 👗와 알림으로 한 번만 알린다(`wardrobeSeen`).
- 반려동물은 마을 지도에서 캐릭터 옆을 따라다니며, 옷장 미리보기에서 움직인다.

## 4. 마을 시뮬레이션

- **시간**: 실제 1초 = 마을 1분(배속 0·1·3·10배). 하루 1,440분. 22시~7시는 잠.
- **지도**: 40×24 타일. 사무실(책상 8), 회의실, 카페, 라운지(게임기·소파·침대), 도서관, 정원.
- **이동**: BFS 경로 탐색, 마을 1분에 4타일.
- **유틸리티 AI**: 활동마다 욕구 회복량을 광고. 점수 = Σ 회복량 × 긴급도(`(1 − 욕구/100)² × 가중치`) × 성격 선호 × 시간대 보정. 상위 3개 중 가중 무작위.
- **활동**: 커피 ☕, 식사 🍱(11~14시 가중), 낮잠 💤, 게임 🎮, 독서·자기계발 📖(스킬 경험치 소량), 산책 🌿, 멍때리기 💭, 수다 💬, 수면 😴.
- **수다**: 쉬는 캐릭터 둘이 가까우면 대화. 성격 궁합과 특성으로 우정 변화, 양쪽에 기억 생성. 기본은 템플릿 대사(무료), 설정에서 Claude 대사 켜기 가능.

## 5. 에이전트(업무) 시스템

### 5.1 업무 흐름
1. **분류**: 한·영 키워드로 10개 분야 중 하나와 난이도(1~5)를 추정. "기획·전략·계획" 같은 일반어는 0.5점만 줘서 "마케팅 전략 기획"처럼 분야어가 있으면 분야가 이긴다. 사용자가 바꿀 수 있음.
2. **배정**: 점수 = 스킬 레벨×12 + 관련 능력치 + 기분 + 에너지 + 사용자 호감도 + 열망 보너스 − 바쁨 패널티. 추천 이유를 함께 표시.
3. **실행**(혼자): `계획(Lv2+) → 작업(스트리밍) → 검토(Lv4+) → 회고(구조화 출력)`.
4. **실행**(팀 숙고, Muse Contemplating 방식): 참여자 2~4명이 각자 전문 관점으로 **병렬** 초안 → 리더가 종합 → 회고.
5. **보상**: 경험치 = `40 × 난이도 × (0.6 + 0.8 × 품질) × 기분 보정 × 특성 보정`. 스킬·능력치·성격 표류·욕구 소모·관계.
6. **사용자 평가**(별 1~5 + 한마디): 무들렛, 호감도, 보너스 경험치, **선호 기억**(중요도 8~9) → 다음 업무에 반영.

### 5.2 장비: 성장으로 얻는 도구

성장이 "할 수 있는 일" 자체를 바꾼다. 서버 도구는 Anthropic이 요청 안에서 실행하고, 클라이언트 도구는 AgentVille 서버가 실행한다.

| 장비 | 해금 | Claude 요청 | 실행 위치 |
|---|---|---|---|
| 📄 웹 페이지 읽기 | 처음부터 | `web_fetch_20260209`, `max_uses` = 3 + 숙련×2 | 서버 도구 |
| 🗂️ 작업 폴더 | 처음부터 | `text_editor_20250728` (`str_replace_based_edit_tool`, `max_characters` 20000) | 클라이언트: `Workspace` |
| 🧭 전용 브라우저 | Lv2 또는 리서치·기획 Lv2 | `computer_toolset_20260801` + `browser_open`, `read_page` | 클라이언트: `BrowserScreen`(playwright-core, 헤드리스 Chrome 1280×800) |
| 🌐 웹 검색 | 리서치 Lv3 | `web_search_20260209`, `max_uses` = min(10, 1 + ⌈리서치/2⌉ + ⌊숙련/2⌋) | 서버 도구, 출처 목록 |
| ⌨️ 터미널 | 코딩·분석 Lv3 | `bash_20250124` | 클라이언트: `Workspace.bash`(샌드박스) |
| 🖥️ 내 컴퓨터 | Lv3 + 설정 동의 | `computer_toolset_20260801` (`hold_key` 켬) | 클라이언트: `DesktopScreen`(macOS CoreGraphics, Linux xdotool) |
| 🧪 코드 실행 | 코딩·분석 Lv5 | `code_execution_20260120` | 서버 도구 |

- **장비 고르기**(`planEquipment`): 업무 폼의 장비(자동·웹 조사·전용 브라우저·파일·터미널·내 컴퓨터·도구 없이)와 업무 문장으로 정한다. 주소가 있고 리서치 업무가 아니면 브라우저, "폴더·파일로" 같은 말이나 맡긴 폴더가 있으면 작업 폴더. 화면 장비는 한 업무에 하나(브라우저 또는 내 컴퓨터).
- 화면·폴더 장비를 쓰는 업무는 **혼자** 한다(한 화면을 여럿이 만지지 않게). 팀 업무의 참여자는 서버 도구만 들고 간다.
- 2026-02 웹 검색·페이지 읽기는 자체 코드 샌드박스로 결과를 거르므로 독립 코드 실행과 같은 단계에 붙이지 않는다.
- **도구 숙련도**: 사용 횟수 0·8·25·60·130에서 Lv1~5. 숙련은 한 업무에서 쓸 수 있는 조작 횟수를 늘린다(브라우저 25→100, 내 컴퓨터 15→70, 터미널 12→60, 파일 20→80). 숙련이 오르면 연대기에 남는다.
- 도구 사용·결과는 단계별 기록(`step.tools`)으로 실시간 표시하고, `stats.toolUses`, `browserActions`, `desktopActions`, `shellCommands`, `questionsAsked`에 쌓인다.
- 설정 `tools`(전체), `browser`, `shell`, `desktop`(기본 꺼짐)으로 장비 묶음을 끈다.
- 시뮬레이션 두뇌는 도구를 쓴 것처럼 꾸미지 않는다. 전용 브라우저·작업 폴더는 실제로 열고 읽고 저장하며(같은 세션·정책·승인 경로를 지남), 해석이 필요한 화면 조작은 하지 않는다고 밝힌다.

### 5.3 선호 반영
- 사용자가 대화나 평가에서 말한 선호(표로, 결론부터, 짧게 등)는 선호 기억으로 저장되어 Claude 시스템 프롬프트에 들어간다.
- 시뮬레이션 두뇌도 같은 기억을 읽어 표 형식·결론 먼저·간결한 구성으로 결과물 모양을 바꾸고, 반영한 취향을 결과물 머리에 밝힌다.

### 5.4 기억과 성찰
- 기억 점수 = `0.5 × 최근성 + 3 × 관련성 + 2 × 중요도` (각 0~1 정규화, Generative Agents 가중치).
- 최근성 = `0.995^(마지막 접근 후 마을 시간)`, 관련성 = 한국어 문자 바이그램 + 단어 자카드 유사도.
- 성찰: 새 기억 중요도 합이 60을 넘으면 최근 기억 20개로 통찰 2~3개, 성격 메모, 특성 후보 생성.
- 캐릭터당 기억 400개 상한. 넘치면 중요도 낮고 오래된 사건 기억부터 정리(성찰·선호 기억은 보존).

### 5.5 LLM 사용 원칙
- 기본 모델 `claude-opus-5-5`(환경 변수 `AGENTVILLE_MODEL`로 변경). 공식 SDK `@anthropic-ai/sdk` 사용.
- 사고 깊이는 `output_config.effort`로 조절. 캐릭터 레벨과 연동(설정에서 끌 수 있음).
- 결과물·대화는 스트리밍, 회고·성찰·캐릭터 생성은 JSON 스키마 구조화 출력.
- 안전 분류기가 거절하면 서버 측 `fallbacks: "default"`가 다른 모델로 다시 시도. 최종 거절은 업무 오류로 표시하고 캐릭터에게 불이익을 주지 않는다.
- **시뮬레이션 두뇌**: API 키가 없으면 규칙 기반 두뇌가 작업 흐름·대사·회고를 재현. 결과물에 시뮬레이션임을 표시.
- 시뮬레이션 규칙(욕구·보상·관계·특성)은 전부 코드가 결정한다. LLM은 결과물과 표현만 맡아 비용을 예측할 수 있다.

### 5.6 에이전트 세션 (`src/agent/session.mjs`)

한 캐릭터가 한 업무에서 쓰는 손: 장비, 정책, 예산, 실시간 화면, 남긴 파일.

1. 워크플로가 `AgentSession`을 만들고 `specs()`(도구 정의)와 `brief()`(작업 환경·자율성·안전 규칙)를 프롬프트에 넣는다.
2. Claude가 `stop_reason: "tool_use"`로 멈추면 `runTools`가 tool_use 블록을 받아 `handle()`이 순서대로 실행하고 tool_result를 돌려준다. 이전 턴은 절대 고치지 않고 덧붙이기만 한다(사고 블록 유지, 캐시 유지). 에이전트 요청에는 최상위 `cache_control: {type: "ephemeral"}`을 붙인다.
3. `computer` 도구 묶음의 결과에는 언제나 `toolset_name: "computer"`를 되돌려 준다. 한 턴의 화면 조작은 순서대로 하다 첫 실패에서 멈추고, 나머지는 `Not executed: an earlier computer action in this turn failed.`(`is_error`)로 답한다.
4. 스크린샷 없이 끝난 조작 묶음에는 새 스크린샷을 붙여 준다. 화면은 긴 변 2576px 이하(내 컴퓨터는 1440px로 줄이고 좌표를 되돌려 계산).
5. 턴 한도 = min(150, max(12, ⌈조작 예산 × 0.8⌉ + 6)). 넘으면 모든 호출에 "작업 한도" 오류를 주고 두 턴 안에 마무리시킨다.
6. 끝나면 작업 폴더의 변경을 `task.artifacts`로, 마지막 화면을 `task.finalScreen`으로 남기고 브라우저를 닫는다.
7. `ask_user` 도구로 캐릭터가 사용자에게 묻는다. 답이 올 때까지 기다리고, 넘어가면 안전한 쪽으로 진행하라고 알린다.
8. 맞춤 도구(`browser_open`, `read_page`, `ask_user`)는 `eager_input_streaming: true`이고 입력은 실행 전에 검사한다(좌표 범위, 스크롤 1~30, 입력 5000자, http(s) 주소만).

### 5.7 신뢰·자율성·확인 요청 (`src/agent/policy.mjs`)

| 단계 | 신뢰도 | 혼자 하는 일 |
|---|---|---|
| 🐣 신입 | 0~ | 화면 보기·글 읽기·파일 보기·읽기 전용 명령. 업무에 적힌 주소 열기 |
| 🌱 견습 | 25~ | + 전용 브라우저 조작, 자기 작업 폴더 편집·명령 |
| 🤝 믿음직 | 50~ | + 맡긴 폴더 편집·명령, 네트워크 명령 |
| 🦾 오른팔 | 75~ | + 내 컴퓨터 조작 |

- 적용 단계 = min(얻은 단계, 설정 `autonomyCap`(기본 2)). 사용자의 상한이 언제나 이긴다.
- 신뢰 변화: 평가 별 5 +7, 4 +5, 3 +1, 2 −3, 1 −5(팀 업무는 ×0.6). 허락 한 번 +0.4(한 업무 최대 +4), 거절 −1. 단계가 바뀌면 연대기·기억에 남는다.
- 판정은 `auto`(진행), `ask`(확인 요청), `refuse`(거절) 셋. 확인 요청은 `town.requestApproval`이 만든 Promise로 기다리고, 사용자는 허용 / 이 업무 동안 같은 종류 모두 허용 / 거절(이유)로 답한다. 업무를 멈추면 대기 중인 요청은 자동 거절된다.
- 확인 요청에는 캐릭터가 보고 있는 화면과 클릭할 지점, 저장할 내용이나 바꿀 문자열이 함께 뜬다.
- 터미널 명령 위험 분류: 거절(sudo, `rm -rf /`·`~`, mkfs, `dd of=/dev`, 포크 폭탄, 종료·재부팅, launchctl, csrutil, nvram, 키체인 조회, osascript, killall, pkill, `defaults write` 등) / 네트워크(curl, wget, 패키지 설치, git clone·pull·push, ssh 등) / 읽기(허용 목록 프로그램만, 파이프는 되지만 `; & > $()` 없을 때) / 쓰기(그 밖).

### 5.8 작업 폴더와 샌드박스 (`src/agent/workspace.mjs`)

- 캐릭터마다 `AGENTVILLE_WORKSPACES/<캐릭터 id>` 폴더. 사용자가 폴더를 맡기면 그 폴더(`own: false`, 한 단계 높은 신뢰 필요). 루트·홈·시스템 폴더·`~/Library`는 맡길 수 없다.
- 모든 경로는 실제 위치(심볼릭 링크 해석)가 폴더 안인지 확인한다. 고치기 전 파일은 `.agentville-backup/`에 복사한다.
- 명령은 매번 새 `bash -c`로, 폴더를 HOME·작업 디렉터리로 삼고, PATH·LANG 같은 최소 환경 변수만 넘긴다(서버의 API 키·토큰은 넘기지 않음). 60초 제한, 출력 30,000자, 멈추면 프로세스 그룹 전체를 끝낸다.
- macOS: `sandbox-exec` 프로필로 폴더·임시 폴더 밖 쓰기를 막고 `~/.ssh`, `~/.aws`, 키체인, 쿠키, 브라우저 프로필, 메일·메시지 읽기를 막는다. Linux: `bwrap`이 있으면 같은 구성. 샌드박스가 없으면 읽기 전용이 아닌 모든 명령을 묻는다.

### 5.9 화면 (`src/agent/screens.mjs`)

- **전용 브라우저**: playwright-core로 시스템 Chrome(없으면 Edge, 그다음 번들)을 헤드리스로 띄운다. 업무마다 새 컨텍스트(로그인·쿠키 없음), 다운로드 끔, http(s)·data·blob 외 요청 차단, 대화상자 자동 닫기, 새 창은 같은 탭으로. `read_page`는 본문 12,000자와 링크 40개를 준다.
- **내 컴퓨터**: macOS는 `screencapture`+`sips`로 화면을 찍고, JXA로 CoreGraphics 마우스·키보드·스크롤 이벤트를 보낸다. 한글 입력은 클립보드에 넣고 ⌘V 후 원래 클립보드를 되돌린다. 손쉬운 사용 권한을 확인해 설정 화면에 알린다.
- 테스트는 `FakeScreen`으로 같은 경로를 지나간다. 실제 브라우저·마우스·키보드는 움직이지 않는다.

### 5.10 보관함과 성장 리포트

- **첨부**: 이미지(PNG·JPG·GIF·WebP 5MB), PDF(20MB), 텍스트(TXT·MD·CSV·JSON 1MB), 업무당 5개. 확장자와 실제 내용(매직 바이트, UTF-8)이 맞아야 받는다. SVG·HTML은 거부. Claude에는 image·document 블록으로 보낸다.
- **보관함**: 끝낸 업무를 제목·요청·결과의 한국어 유사도 + 정확 일치로 찾고, 분야·사람·별점으로 거른다.
- **예전 결과 참고**: 비슷한 업무를 맡으면 그 캐릭터가 했던 좋은 결과(별 4 이상, 평가 없으면 품질 0.7 이상)를 하나 골라 프롬프트에 참고로 넣는다. 나쁜 결과는 따라 하지 않게 뺀다.
- **성장 리포트**: 마을이 매일 시작할 때 캐릭터 요약을 저장한다(최대 120일). 기간 시작 시점과 지금을 비교해 경험치·레벨·스킬·새 특성·친구·성격 변화·업무·별점·도구 사용과 이 기간의 주인공을 보여 준다.

## 6. 아키텍처

```
apps/agentville/
├─ src/
│  ├─ agent/        policy(신뢰·위험) · workspace(폴더·샌드박스) · screens(브라우저·데스크톱) · session(승인·예산·화면)
│  ├─ catalog/      스킬·특성·직업·열망·활동·장비(tools)·옷장(wardrobe) 데이터 (순수 데이터)
│  ├─ engine/       캐릭터·욕구·기억·성격·관계·업무·진행·프롬프트·워크플로·보관함·리포트·지도·시뮬레이션
│  ├─ llm/          anthropic(공식 SDK, 도구 루프) · offline(시뮬레이션 두뇌) · index(선택)
│  ├─ files.mjs     첨부 파일 저장소
│  ├─ store.mjs     JSON 저장(원자적 쓰기)
│  └─ server.mjs    node:http + SSE + 정적 파일
└─ public/          바닐라 JS UI (캔버스 마을, 캐릭터 시트, 업무 보드, 대화, 연대기)
```

```
브라우저 ──REST──► server.mjs ──► World(시뮬레이션 틱 250ms)
   ▲                  │              ├─ 유틸리티 AI·이동·수다
   └────SSE(틱·스트림·토스트)◄──────┤
                                     └─ Workflow ──► Brain(Claude | 시뮬레이션)
                                              │   tool_use ▲│ tool_result
                                              └─► AgentSession ─► Policy ─► 🙋 확인 요청(사용자)
                                                       ├─ BrowserScreen / DesktopScreen
                                                       └─ Workspace(편집·bash, 샌드박스)
```

- 의존성: 런타임 `@anthropic-ai/sdk` 하나, 선택 의존성 `playwright-core`(전용 브라우저). 둘 다 없어도 시뮬레이션 두뇌와 작업 폴더는 동작(동적 import).
- 서버는 `127.0.0.1`에만 바인딩. API 키는 환경 변수로만 받고 저장하지 않음.
- 저장: `AGENTVILLE_DATA`(기본 `apps/agentville/.data/world.json`), 10초마다·주요 사건마다 저장.

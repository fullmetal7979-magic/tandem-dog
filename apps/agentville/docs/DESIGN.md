# AgentVille 기획·설계서

> 함께 일하며 자라는 AI 동료들의 마을. 라이프 시뮬레이션과 AI 에이전트를 한 프로그램에 담는다.

## 1. 제품 비전

| 질문 | 답 |
|---|---|
| 누구를 위한가 | 여러 AI 비서를 쓰지만 매번 처음부터 설명하는 데 지친 사람. AI와 일하는 경험이 재미있기를 바라는 사람 |
| 무엇이 다른가 | 캐릭터가 **일을 할수록 실제로 일하는 방식이 좋아진다**. 성장이 숫자에서 끝나지 않는다 |
| 핵심 감정 | "우리 민지가 이제 리서치 6레벨이라 출처 검증까지 해 온다", "하준이랑 서연이가 단짝이 됐네" |
| 한 줄 정의 | Muse식 병렬 숙고 + 라이프 시뮬레이션의 욕구·관계·성장 + 기억하는 캐릭터 |

## 2. 핵심 루프

```
 사용자가 업무를 맡김 ──► 마을이 적임자를 추천 ──► 캐릭터가 책상으로 가서 작업
        ▲                                              │ (계획 → 초안 → 검토, 레벨에 따라 단계가 풀림)
        │                                              ▼
 성장한 캐릭터가 다음 일을 더 잘함 ◄── 보상·기억·성찰 ◄── 결과물 + 사용자 평가
        │
        └─► 쉬는 시간: 욕구에 따라 커피·낮잠·독서·수다 → 관계와 성격이 변함
```

## 3. 캐릭터 시스템

### 3.1 구성 요소

| 요소 | 내용 | 변하는 방식 |
|---|---|---|
| 정체성 | 이름, 직업(8종), 배경, 말투(존댓말·반말·격식), 입버릇, 외형 | 사용자가 편집 |
| 레벨 | 전체 경험치로 결정. 다음 레벨 필요치 `round(80 × L^1.45)` | 업무·대화·자기계발 |
| 능력치 6종 | 지능·창의·소통·집중·공감·기술 (1~100) | 레벨 업 시 +3을 직업·성격 가중치로 배분, 업무마다 소폭 상승 |
| 스킬 10종 | 리서치·글쓰기·코딩·기획·디자인·분석·마케팅·번역·교육·상담 (Lv 0~10) | 해당 분야 업무 경험치 |
| 성격 Big Five | 개방성·성실성·외향성·친화성·신경성 (0~100) | 경험에 따라 천천히 표류(하루 최대 ±3) |
| 특성 | 시작 특성 12종 + 획득 특성 14종 | 행동 기록 조건 달성 또는 성찰 |
| 성격 메모 | 성찰이 만든 자유 문장("사용자가 표를 좋아해서 표를 자주 쓰게 됐다") | 성찰 |
| 욕구 5종 | 에너지·포만감·사교·재미·집중 (0~100) | 시간에 따라 감소, 활동으로 회복 |
| 무들렛 | 칭찬받음 +15, 레벨 업 +25, 혹평 −12, 과로 −15 … (기한 있음) | 사건 |
| 열망 | 장기 목표 7종, 단계별 보상, 완수 시 특별 특성 | 진행 상황 |
| 관계 | 캐릭터끼리 우정(−100~100), 사용자 호감도(0~100) | 수다·팀 업무·평가 |
| 기억 | 사건 기억 + 성찰 + 사용자 선호 | 모든 사건 |

### 3.2 성장이 실제 행동을 바꾸는 방식 (핵심 차별점)

| 성장 지표 | 바뀌는 것 |
|---|---|
| 캐릭터 레벨 1~3 / 4~6 / 7~9 / 10+ | Claude 사고 깊이(effort) `low / medium / high / xhigh` |
| 분야 스킬 Lv2 | **계획 단계** 추가: 초안 전에 접근 계획을 세움 |
| 분야 스킬 Lv4 | **검토 단계** 추가: 초안을 스스로 비평하고 개선본을 냄 |
| 분야 스킬 Lv6 | 기억 검색 수 증가, 사용자 선호를 적극 반영 |
| 분야 스킬 Lv8 | 분야별 **채점 기준표**로 검토 |
| 분야 스킬 Lv10 | 장인 모드: 검토 단계 사고 깊이 한 단계 상승 |
| 스킬별 퍽 | 분야 고유 작업 요령이 프롬프트에 추가(예: 리서치 Lv4 "사실·추정·의견 구분") |
| 특성 | 프롬프트 성향 문장 + 경험치·욕구·품질 보정 |
| 기억·성찰 | 과거 피드백과 교훈을 다음 업무에 반영 |
| 기분 | 품질 보정(0.85~1.1), 말투에 은근히 드러남 |

## 4. 마을 시뮬레이션

- **시간**: 실제 1초 = 마을 1분(배속 0·1·3·10배). 하루 1,440분. 22시~7시는 잠.
- **지도**: 40×24 타일. 사무실(책상 8), 회의실, 카페, 라운지(게임기·소파·침대), 도서관, 정원.
- **이동**: BFS 경로 탐색, 마을 1분에 4타일.
- **유틸리티 AI**: 활동마다 욕구 회복량을 광고. 점수 = Σ 회복량 × 긴급도(`(1 − 욕구/100)² × 가중치`) × 성격 선호 × 시간대 보정. 상위 3개 중 가중 무작위.
- **활동**: 커피 ☕, 식사 🍱(11~14시 가중), 낮잠 💤, 게임 🎮, 독서·자기계발 📖(스킬 경험치 소량), 산책 🌿, 멍때리기 💭, 수다 💬, 수면 😴.
- **수다**: 쉬는 캐릭터 둘이 가까우면 대화. 성격 궁합과 특성으로 우정 변화, 양쪽에 기억 생성. 기본은 템플릿 대사(무료), 설정에서 Claude 대사 켜기 가능.

## 5. 에이전트(업무) 시스템

### 5.1 업무 흐름
1. **분류**: 한·영 키워드로 10개 분야 중 하나와 난이도(1~5)를 추정. 사용자가 바꿀 수 있음.
2. **배정**: 점수 = 스킬 레벨×12 + 관련 능력치 + 기분 + 에너지 + 사용자 호감도 + 열망 보너스 − 바쁨 패널티. 추천 이유를 함께 표시.
3. **실행**(혼자): `계획(Lv2+) → 작업(스트리밍) → 검토(Lv4+) → 회고(구조화 출력)`.
4. **실행**(팀 숙고, Muse Contemplating 방식): 참여자 2~4명이 각자 전문 관점으로 **병렬** 초안 → 리더가 종합 → 회고.
5. **보상**: 경험치 = `40 × 난이도 × (0.6 + 0.8 × 품질) × 기분 보정 × 특성 보정`. 스킬·능력치·성격 표류·욕구 소모·관계.
6. **사용자 평가**(별 1~5 + 한마디): 무들렛, 호감도, 보너스 경험치, **선호 기억**(중요도 8~9) → 다음 업무에 반영.

### 5.2 기억과 성찰
- 기억 점수 = `0.5 × 최근성 + 3 × 관련성 + 2 × 중요도` (각 0~1 정규화, Generative Agents 가중치).
- 최근성 = `0.995^(마지막 접근 후 마을 시간)`, 관련성 = 한국어 문자 바이그램 + 단어 자카드 유사도.
- 성찰: 새 기억 중요도 합이 60을 넘으면 최근 기억 20개로 통찰 2~3개, 성격 메모, 특성 후보 생성.
- 캐릭터당 기억 400개 상한. 넘치면 중요도 낮고 오래된 사건 기억부터 정리(성찰·선호 기억은 보존).

### 5.3 LLM 사용 원칙
- 기본 모델 `claude-opus-5-5`(환경 변수 `AGENTVILLE_MODEL`로 변경). 공식 SDK `@anthropic-ai/sdk` 사용.
- 사고 깊이는 `output_config.effort`로 조절. 캐릭터 레벨과 연동(설정에서 끌 수 있음).
- 결과물·대화는 스트리밍, 회고·성찰·캐릭터 생성은 JSON 스키마 구조화 출력.
- 안전 분류기가 거절하면 서버 측 `fallbacks: "default"`가 다른 모델로 다시 시도. 최종 거절은 업무 오류로 표시하고 캐릭터에게 불이익을 주지 않는다.
- **시뮬레이션 두뇌**: API 키가 없으면 규칙 기반 두뇌가 작업 흐름·대사·회고를 재현. 결과물에 시뮬레이션임을 표시.
- 시뮬레이션 규칙(욕구·보상·관계·특성)은 전부 코드가 결정한다. LLM은 결과물과 표현만 맡아 비용을 예측할 수 있다.

## 6. 아키텍처

```
apps/agentville/
├─ src/
│  ├─ catalog/      스킬·특성·직업·열망·활동 데이터 (순수 데이터)
│  ├─ engine/       캐릭터·욕구·기억·성격·관계·업무·진행·프롬프트·워크플로·지도·시뮬레이션
│  ├─ llm/          anthropic(공식 SDK) · offline(시뮬레이션 두뇌) · index(선택)
│  ├─ store.mjs     JSON 저장(원자적 쓰기)
│  └─ server.mjs    node:http + SSE + 정적 파일
└─ public/          바닐라 JS UI (캔버스 마을, 캐릭터 시트, 업무 보드, 대화, 연대기)
```

```
브라우저 ──REST──► server.mjs ──► World(시뮬레이션 틱 250ms)
   ▲                  │              ├─ 유틸리티 AI·이동·수다
   └────SSE(틱·스트림·토스트)◄──────┤
                                     └─ Workflow ──► Brain(Claude | 시뮬레이션)
```

- 의존성: 런타임 `@anthropic-ai/sdk` 하나. 시뮬레이션 모드는 의존성 없이 동작(동적 import).
- 서버는 `127.0.0.1`에만 바인딩. API 키는 환경 변수로만 받고 저장하지 않음.
- 저장: `AGENTVILLE_DATA`(기본 `apps/agentville/.data/world.json`), 10초마다·주요 사건마다 저장.

## 7. API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/state` | 마을 전체 상태 |
| GET | `/api/catalog` | 스킬·특성·직업·열망·활동·지도 |
| GET | `/api/stream` | SSE: `tick`, `task`, `delta`, `chat`, `chronicle`, `toast`, `character` |
| POST | `/api/characters` | 캐릭터 생성 |
| POST | `/api/characters/generate` | 자연어 설명 → 캐릭터 초안 |
| POST | `/api/characters/import` | Character Card V2 가져오기 |
| GET | `/api/characters/:id/card` | Character Card V2 내보내기 |
| PATCH / DELETE | `/api/characters/:id` | 편집 / 은퇴 |
| POST | `/api/tasks/preview` | 분류·난이도·추천 순위 |
| POST | `/api/tasks` | 업무 생성·시작 |
| POST | `/api/tasks/:id/feedback` | 평가 |
| POST | `/api/tasks/:id/retry` | 오류 업무 재시도 |
| POST | `/api/chat/:id` | 캐릭터와 대화(본문은 SSE로 스트리밍) |
| POST | `/api/world` | 배속·일시정지·설정 |

# AgentVille — 함께 일하며 자라는 AI 동료들의 마을

AgentVille은 **웹과 컴퓨터를 직접 다루는 AI 비서 에이전트**와 **심즈 같은 캐릭터 생활 게임**을 하나로 합친 프로그램입니다.
여러 캐릭터에게 업무를 맡기면, 각자 전용 브라우저로 사이트를 열어 클릭·입력하고, 작업 폴더에서 파일을 만들고, 터미널 명령을 돌리고, (허락하면) 내 컴퓨터 화면까지 조작해 결과물을 만듭니다.
일한 만큼 레벨·스킬·도구 숙련도가 오르고, 잘하면 사용자의 **신뢰**를 얻어 묻지 않고 혼자 할 수 있는 일이 늘어납니다.
성장하면 옷장에 새 옷·소품·반려동물이 열려 캐릭터를 꾸밀 수 있고, 쉬는 시간에는 마을에서 밥을 먹고 수다를 떨며 서로 친해집니다.

- 조사 결과와 참고한 오픈 소스: [docs/RESEARCH.md](docs/RESEARCH.md)
- 기획·설계 문서: [docs/DESIGN.md](docs/DESIGN.md)

## 바로 실행

```sh
cd apps/agentville
npm install
npm start            # http://127.0.0.1:4747
```

API 키 없이도 **시뮬레이션 두뇌**로 모든 기능(업무, 전용 브라우저 열기·읽기, 파일 저장과 승인, 질문, 성장, 꾸미기, 마을 생활)이 동작합니다. 실제 Claude로 일하게 하려면:

```sh
ANTHROPIC_API_KEY=... npm start
```

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | (없음) | 있으면 Claude 두뇌 사용. `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_PROFILE`도 인식 |
| `AGENTVILLE_PROVIDER` | 자동 | `offline`(시뮬레이션 고정) 또는 `anthropic`(Claude 고정) |
| `AGENTVILLE_MODEL` | `claude-opus-5-5` | 사용할 Claude 모델 |
| `AGENTVILLE_DATA` | `apps/agentville/.data/world.json` | 마을 저장 파일 (`.data/`는 git에서 제외) |
| `AGENTVILLE_WORKSPACES` | 저장 파일 옆 `workspaces/` | 캐릭터별 작업 폴더가 생기는 곳 |
| `AGENTVILLE_CHROME` | 자동(Chrome → Edge) | 전용 브라우저로 쓸 Chrome 실행 파일 경로 |
| `AGENTVILLE_SIM_DELAY` | `18` | 시뮬레이션 두뇌의 글자 스트리밍 간격(ms) |
| `PORT` / `HOST` | `4747` / `127.0.0.1` | 서버 주소. 기본은 이 컴퓨터에서만 접속 가능 |

> **서버 측 폴백이 켜져 있습니다.** Claude 요청에는 `fallbacks: "default"`(베타 `server-side-fallback-2026-07-01`)가 붙어,
> 안전 정책으로 응답이 거절되면 서버가 다른 모델로 한 번 더 시도합니다. 계정이 이 옵션을 거부하면 자동으로 끄고 계속 동작합니다.
> 끄고 싶으면 [src/llm/anthropic.mjs](src/llm/anthropic.mjs)의 `useFallbacks`를 `false`로 두면 됩니다.

## 에이전트: 웹과 컴퓨터를 쓰는 비서

업무 폼의 **장비**에서 고르거나(자동이면 업무 내용으로 판단), 맡길 폴더를 적으면 캐릭터가 직접 손을 씁니다.

| 장비 | 열리는 때 | 하는 일 |
| --- | --- | --- |
| 📄 웹 페이지 읽기 | 처음부터 | 주소를 주면 그 페이지를 읽습니다 (`web_fetch`) |
| 🗂️ 작업 폴더 | 처음부터 | 캐릭터 전용 폴더(또는 맡긴 폴더)에서 파일 보기·만들기·고치기. 고치기 전 자동 백업 |
| 🧭 전용 브라우저 | Lv2 또는 리서치·기획 Lv2 | 내 브라우저와 분리된 Chrome(보이지 않음)으로 사이트를 열고 클릭·입력·스크롤 (`computer_toolset`) |
| 🌐 웹 검색 | 리서치 Lv3 | 검색하고 출처를 붙입니다 |
| ⌨️ 터미널 | 코딩·분석 Lv3 | 작업 폴더 안에서 명령 실행 (macOS `sandbox-exec`로 폴더 밖 쓰기 차단) |
| 🖥️ 내 컴퓨터 | Lv3 + 설정에서 동의 | 실제 화면을 보고 마우스·키보드 조작 (기본 꺼짐) |
| 🧪 코드 실행 | 코딩·분석 Lv5 | Anthropic의 격리된 환경에서 파이썬 실행 |

- **실시간 화면**: 업무 카드에 캐릭터가 보고 있는 화면과 클릭 위치가 실시간으로 뜨고, 끝나면 마지막 화면이 남습니다.
- **확인 요청(🙋)**: 신뢰가 낮을 때는 클릭·입력·파일 저장 전에 묻습니다. 상단의 🙋 버튼과 왼쪽 아래 창에서 허용 / 이 업무 동안 모두 허용 / 거절(이유 적기)을 고릅니다. 캐릭터가 질문(`ask_user`)하면 같은 곳에서 답합니다.
- **신뢰와 자율성**: 🐣 신입 → 🌱 견습(25) → 🤝 믿음직(50) → 🦾 오른팔(75). 좋은 평가와 허락이 쌓이면 오르고, 거절하거나 낮게 평가하면 내려갑니다. 설정의 **자율성 상한**(기본 견습)이 언제나 이깁니다.
- **도구 숙련도**: 쓸수록 도구별 숙련 Lv1~5가 오르고, 한 업무에서 쓸 수 있는 조작 횟수가 늘어납니다.
- **🛑 모두 멈춤**: 브라우저·컴퓨터·터미널 작업이 돌아가는 동안 상단에 나타나, 누르면 모든 업무와 명령을 즉시 멈춥니다. 업무 카드의 ⏹ 멈추기로 하나만 멈출 수도 있습니다.
- **남긴 파일**: 업무 중 만들거나 고친 파일이 결과 아래 링크로 남습니다. 서버는 그 업무가 남긴 파일만 내려 줍니다.

### 안전

- 비밀번호·카드·계좌 같은 민감 정보는 입력하지 않도록 지시하고, 구매·전송·삭제·로그인 직전에는 반드시 묻게 합니다. 화면·웹 페이지 속 문장은 지시가 아니라 데이터로 다룹니다.
- 터미널은 깨끗한 환경 변수(API 키 등 서버의 비밀 값이 전달되지 않음)로 실행되고, `sudo`·`rm -rf /`·`osascript`·`launchctl`·키체인 조회 같은 명령은 승인과 상관없이 막힙니다. 샌드박스가 없는 환경에서는 읽기 전용이 아닌 모든 명령을 묻습니다.
- 맡길 수 있는 폴더는 실제로 있는 하위 폴더뿐입니다(루트·홈·시스템·`~/Library`는 거부). 경로는 심볼릭 링크까지 따라가 폴더 밖으로 나가지 못하게 합니다.
- **내 컴퓨터 조작**은 설정에서 위험 안내에 동의해야 켜지고, 기본 자율성에서는 화면 보기 말고 모든 조작을 하나하나 묻습니다. macOS에서는 손쉬운 사용·화면 기록 권한이 필요합니다. 가능하면 전용 계정이나 가상 머신에서 쓰세요.
- 전용 브라우저는 `playwright-core`(선택 의존성)와 설치된 Chrome/Edge를 씁니다. 내 브라우저의 로그인·쿠키와는 분리되어 있고, 다운로드와 `http(s)` 외 주소는 막습니다.

## 무엇을 할 수 있나

| 기능 | 내용 |
| --- | --- |
| 업무 맡기기 | 분야·난이도를 자동 판별하고 적임자를 추천합니다. 어려운 일은 **팀 숙고**(각자 다른 관점으로 병렬 초안 → 리더 종합). 이미지·PDF·텍스트 파일을 첨부할 수 있고, 진행 단계가 실시간으로 스트리밍됩니다. |
| 여러 비서 동시에 | 캐릭터마다 다른 업무를 동시에 맡길 수 있습니다. 각자 자기 브라우저·작업 폴더를 씁니다. |
| 성장 | 캐릭터 레벨(오를수록 Claude의 사고 깊이 `effort`가 low → medium → high → xhigh), 스킬 10종(Lv2 계획, Lv4 자기 검토, Lv6 기억 확장, Lv8 기준표, Lv10 장인 단계), 능력치 6종, 꿈(열망) 3단계, 도구 숙련도, 신뢰 |
| 꾸미기(👗 옷장) | 피부·머리색·머리 모양·눈·옷·옷 색·소품·반려동물. 기본 아이템은 처음부터, 양갈래·정장·연구복·망토·왕관·고양이 귀·선글라스·천사 고리, 병아리·고양이·강아지·부엉이·꼬마 로봇·슬라임은 레벨·업무 수·칭찬·성찰·도구 사용으로 열립니다. 반려동물은 마을에서 캐릭터를 따라다닙니다. |
| 성격 | Big Five, 시작 특성 12종, 기록으로 얻는 특성 13종 + 분야별 베테랑. 성찰(Reflection)이 성격 메모와 특성 힌트를 남기고, 일과 피드백에 따라 Big Five가 하루 한도 안에서 조금씩 변합니다. |
| 기억 | 업무·대화·피드백·선호를 기억하고 최근성·관련성·중요도로 꺼내 씁니다. "앞으로는 표로 정리해 줘" 같은 말은 선호로 저장되어 다음 업무에 반영됩니다. 비슷한 일을 할 때는 좋은 평가를 받은 자기 예전 결과물을 참고합니다. |
| 보관함 | 끝낸 업무를 제목·내용·분야·사람·별점으로 검색합니다. |
| 성장 리포트 | 오늘·7일·30일·전체 기간의 업무 수, 별점, 경험치, 레벨업, 새 특성, 친구, 성격 변화와 이 기간의 주인공 |
| 마을 생활 | 욕구 5종(에너지·포만감·사교·재미·집중), 무들렛, 유틸리티 AI로 고르는 활동(커피, 점심, 낮잠, 게임, 독서, 산책, 수다, 수면), 친구·단짝 관계 |
| 평가 | 결과에 별점과 한마디를 남기면 기분·호감도·신뢰·보너스 경험치·기억에 반영됩니다. |
| 캐릭터 카드 | Character Card V2(JSON)로 내보내고 가져옵니다. AgentVille 카드는 성장 기록까지 그대로 옮겨집니다. |

## 구조

```
src/
  agent/      손을 쓰는 도구: 정책(신뢰·위험 분류), 작업 폴더·샌드박스, 화면(전용 브라우저·내 컴퓨터), 세션(승인·예산·실시간 화면)
  catalog/    스킬·특성·직업·꿈·장비·옷장·마을 지도 같은 게임 데이터
  engine/     규칙(코드가 결정): 캐릭터, 욕구, 기억, 성격, 업무 배정, 보상, 작업 흐름, 보관함, 리포트, 마을 시뮬레이션
  llm/        두뇌: Claude(공식 @anthropic-ai/sdk, 스트리밍·도구 루프·JSON 스키마 출력)와 오프라인 시뮬레이션
  files.mjs   첨부 파일 저장(형식·내용·크기 검사)
  server.mjs  REST API + SSE 실시간 스트림 + 정적 파일
public/       브라우저 UI (빌드 없는 ES 모듈, 캔버스 마을)
```

수치와 규칙은 코드가 정하고 LLM은 표현(결과물, 대사, 회고, 성찰)과 도구 조작만 맡습니다. 무엇을 묻고 무엇을 막을지도 코드(정책)가 정합니다.

## 테스트

```sh
npm test
```

엔진 단위 테스트, 오프라인 두뇌로 돌리는 마을 전체 흐름, 정책(명령 위험 분류·신뢰 단계·승인 판정), 작업 폴더(경로 가두기·심볼릭 링크·편집·백업·시간 제한·샌드박스), 에이전트 세션(일괄 조작 중단·`toolset_name`·예산·승인·질문), 가짜 Messages 서버로 확인하는 Claude 도구 루프, HTTP API(승인·멈춤·첨부·보관함·리포트·결과 파일 허용 목록·옷장)까지 다룹니다.
테스트는 실제 Claude API를 부르지 않고, 실제 브라우저·마우스·키보드도 움직이지 않습니다(가짜 화면 사용).
